# Image Collection & Basic Processing

## 📌 Project Overview
This project demonstrates the workflow of collecting, cleaning, and processing image datasets using Python. The dataset includes categories like cats, dogs, and birds, and prepares the data for machine learning and computer vision tasks.

---

## 🚀 Features
- Download images using Google Image Crawler
- Organize images into category folders
- Remove corrupted images
- Analyze image properties
- Convert images into NumPy arrays
- Create structured datasets using Pandas

---

## 🛠️ Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Pillow (PIL)
- OpenCV
- icrawler

---

## 📂 Dataset Categories
- Cats
- Dogs
- Birds

---

## 📊 Processing Tasks
- Image collection
- Data cleaning
- Image resizing
- Color mode analysis
- Feature extraction
- Dataset preparation

---


## 📈 Output
- Clean image dataset
- Image analysis results
- Machine learning ready dataset
